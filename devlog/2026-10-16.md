### 实现

- `EventDetector` 每轮完整读取 HUD，以 ID 保存最近 `(time, 规范化 msg)`；新增 ID 或同 ID 指纹变化进入现有解析，仍按 ID 排序保留既有同轮事件选择。
- 首次成功读取仅建立基线；之后不因对局、模式或设备连接变化重置。无效对局、事件开关关闭和 CAS 关闭时仍消费历史，不恢复补发；失败、空快照及记录暂时消失不清除已知指纹。
- `last_dmg_id` 仅保留为诊断用历史最大 ID；底层读取接口仍支持增量参数，主程序事件字典与预览／会话输出资格不变。
- 增加首次基线、新增／同 ID 更新、匹配结果及无效对局消费日志。完整快照未变化时不重复打印。
- ID、时间和规范化文本完全相同时无法可靠判断发生了新事件，按重复处理。指纹后续确实发生变化（包括回到先前值）仍视为可观察的变化，不使用永久去重集合。
- 更新技术规格、连接行为说明、开发计划及历史设计记录，标明原“ID 跨局只增不减”假设已失效。
