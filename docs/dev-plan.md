## 开发原则
- 每个阶段完成后验证再进入下一阶段
- 每个模块保持独立，通过明确接口通信
- 所有用户可见字符串使用中文
- 代码注释使用中文

## 技术方案（最终采用）
- GUI: PySide6（Qt 桌面界面，详见 `docs/ui-redesign.md`）
- 郊狼 V3: pydglab-ws 本机服务端
- 郊狼 V4: 按官方 V4 RPC 帧实现的 Relay 客户端
- 游戏数据: requests 轮询 localhost:8111
- 打包: PyInstaller `--onedir` → 版本目录 + ZIP
