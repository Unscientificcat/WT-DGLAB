# 托盘、配置持久化与图标更新开发文档

## 目标

本次更新只调整现有程序的生命周期、配置持久化和品牌资源，不增加新的游戏联动功能。

1. 点击主窗口右上角关闭按钮后隐藏到 Windows 系统托盘，程序和联动服务继续运行。
2. 双击托盘图标恢复主窗口；托盘右键菜单提供“显示主窗口”和“退出程序”。
3. 只有点击托盘菜单中的“退出程序”才停止输出、断开连接并结束进程。
4. 配置固定保存到 EXE 所在目录的 `config.json`；文件不存在时启动即生成。
5. 关闭到托盘和托盘退出时，自动保存界面当前填写的设置，包括尚未点击“保存设置”的内容。
6. 使用项目根目录的 `tubiao1.jpg` 生成 Windows 多尺寸图标和界面品牌图片。

## 设计方案

### 应用目录与配置

- 源码运行：应用目录为项目根目录。
- PyInstaller 运行：应用目录为 `sys.executable` 所在目录，不使用临时解压目录 `sys._MEIPASS`。
- 启动时加载 `config.json`；若文件不存在，立即将默认设置写入该位置。
- 配置保存使用同目录临时文件后原子替换，降低写入中断造成 JSON 损坏的风险。

### 设置自动保存

- 设置面板提供统一的“采集控件并保存”入口。
- 手动保存保持现有校验和操作反馈。
- 自动保存遇到无效的 V4 Relay 地址时保留上一次有效地址，其余设置仍正常保存。
- 关闭到托盘、托盘退出和正常清理阶段均执行保存。

### 系统托盘

- `QApplication.setQuitOnLastWindowClosed(False)` 防止隐藏主窗口时 Qt 自动退出。
- 主窗口关闭事件改为保存设置并隐藏窗口。
- 托盘菜单提供“显示主窗口”和“退出程序”。
- 双击托盘图标恢复并激活主窗口。
- 首次关闭到托盘时显示系统通知，说明程序仍在后台运行。
- 系统托盘不可用时回退为原有的真正退出流程，避免窗口隐藏后无法恢复。

### 单实例与重复启动

- 程序启动时创建稳定的 Windows 命名互斥锁 `WT-DGLAB-single-instance`。
- 首个实例同时监听 Qt 本地 IPC；后续实例不创建业务控制器、不启动轮询和设备连接。
- 后续实例发送 `activate` 请求并等待首实例确认，首实例收到后恢复、提升并激活主窗口。
- 首实例尚在启动时，后续实例会短暂重试连接，避免初始化窗口期间丢失激活请求。
- 激活请求采用应答握手，避免 Windows 命名管道尚未接受连接时消息丢失。

### 图标资源

- 输入：`tubiao1.jpg`，2048 x 2048。
- 输出：`tubiao.ico`，包含 16、20、24、32、40、48、64、128、256 像素尺寸。
- 输出：`tubiao_ui.jpg`，256 x 256，用于界面左上角品牌图标。
- EXE、任务栏、任务管理器、窗口、托盘和界面品牌图统一使用新资源。
