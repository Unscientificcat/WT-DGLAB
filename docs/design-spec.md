## UI 布局

设置面板顶部提供“触发设置”“波形设置”“背景设置”三个页面按钮，按钮下方不设标题文字。触发设置页内的“空战设置”“陆战设置”按钮只切换当前查看的设置页，不改变实际业务模式。波形设置直接显示在主界面设置栏内，顶部切换空战/陆战，左侧选择常规或事件场景，右侧编辑 A/B 波形；常规场景显示随机开关和最小/最大秒数，事件场景显示触发时随机开关。底部提供刷新波形、打开文件夹、保存和取消。

窗口尺寸：960×700（最小 900×650）

```
┌──────────────────────────────────────────┐
│ [状态栏] WT连接 ●  郊狼连接 ●  地址      │
├──────────────┬───────────────────────────┤
│ 实时数据面板  │ 设置面板                  │
│ 过载/速度  [空战]│ - 空战设置/陆战设置      │
│            [陆战]│ - 飞机设置(上下限/通道)  │
│              │ - 飞机设置(上下限/通道)    │
│  🛩 图标     │ - 坦克设置(上下限/通道)    │
│  当前过载值  │ - 连接设置(端口/间隔)      │
│  进度条      │ - 保存/恢复按钮            │
│  A通道强度   │                           │
│  A波形名     │                           │
│  B通道强度   │                           │
│  B波形名     │                           │
├──────────────┴───────────────────────────┤
│ [QR码] 扫码连接  提示文字                │
└──────────────────────────────────────────┘
```

实时状态卡的过载或速度数值右侧放置上下排列的“空战”“陆战”业务模式按钮，当前模式高亮。仪表盘模式切换立即作用于业务控制器并写入配置；设置页查看状态与业务模式互不联动。

## 波形显示（v1 beta_6）

- A/B 通道卡在强度进度条下方显示当前输出波形名小字（"恒定"或 `.pulse` 文件名去后缀），随机换波、事件换波、CAS 切换时实时跟随；卡片可点击（手型光标 + 📈 提示符）。
- 点击通道卡打开该通道独立的"输出电压曲线"非模态窗口：滚动显示最近约 6 秒实际下发电压，纵轴 0-200 与强度条同刻度（A 通道主蓝、B 通道水青），含 50/100/150 网格线、当前强度虚线参考线与"波形 · 强度 · 状态"信息行；未连接郊狼时显示"未连接郊狼设备"；每个通道窗口单例，重复点击置顶。
- 悬浮窗 A/B 通道区为单列纵向排布：A 强度 → A 波形名 → B 强度 → B 波形名（组间留 5px 间隔，波形名为次要文字色小字）。

## 悬浮窗显示内容设置（v1 beta_6）

- 入口两处：主窗口"游戏内悬浮窗"卡片大小滑条下方的"悬浮窗显示内容…"按钮 + 悬浮窗右键菜单首项"显示内容…"，打开同一非模态设置对话框。
- 对话框分三组复选框：基础信息（模式 / 实时过载 G / 实时速度 km/h / 事件提示）、A 通道（输出强度 / 输出波形名）、B 通道（输出强度 / 输出波形名）；共 8 项，默认全开。
- 勾选即时生效并持久化（`overlay_show_*` 配置键）；悬浮窗只显示当前模式的触发指标——空战与陆战上飞机（CAS）显示过载、陆战地面显示速度，开关决定该指标是否显示；未进入对局或数据无效时显示 `--` 占位（沿用旧版行为），数据短暂无效时沿用上次值，切换触发上下文不残留旧指标；"恢复默认"一键全开，悬浮窗大小随内容变化立即调整。

## 关于对话框（beta_6）

- 入口：主窗口顶部状态栏右侧，"注意事项"旁的"关于"文字按钮（objectName `aboutButton`，与 `textButton` 同款样式）。
- 模态对话框，标题"关于 - 郊狼雷霆"，垂直居中排布：品牌图标 64px → 应用名"郊狼雷霆" → 副标题"WAR THUNDER × DG-LAB" → 版本行（主色加粗）→ 分隔线 → 作者行"作者：某不科学的猫酱" → B 站主页链接 → GitHub 仓库链接 → 分隔线 → MIT 许可与非官方声明小字 → "关闭"主按钮。
- B 站主页 `space.bilibili.com/247197404` 与 GitHub 仓库 `github.com/Unscientificcat/WT-DGLAB` 为富文本链接，主色显示，点击调用系统默认浏览器打开；链接文本可鼠标选中复制。
- 版本号来自 `src/version.py` 单一来源（`APP_NAME` + `APP_VERSION`），窗口标题与打包脚本共用，避免关于界面显示过期版本。

## 字体

- 主字体：Microsoft YaHei / Segoe UI / PingFang SC
- 数值大字：28px bold
- 正文：13px
- 提示文字：11-12px

## 交互反馈

- 保存按钮：点击后短暂变绿并显示"✓ 已保存"(1.5s)
- 状态指示灯：绿色圆点 = 已连接，红色圆点 = 未连接
- 进度条：实时反映当前电击强度百分比

## 玻璃主题补充规范

- 主窗口底层使用 `resources/wallpaper_default.png` 或 EXE 同级 `backgrounds/` 中的静态图片。
- 壁纸先增强饱和度，再按窗口逻辑尺寸裁切和模糊；窗口缩放使用防抖缓存。
- 顶栏、实时状态、触发设置、连接面板和波形页外框使用浅色磨砂玻璃；输入框、进度卡和列表项使用半透明实色。
- 背景亮度较低时提高白色叠加层透明度，并保留深灰蓝正文颜色，优先保证文字可读性。
- 背景缺失、损坏或关闭时回退淡蓝底和不透明白面板，不影响业务功能。
- 背景设置页的背景开关和背景选择立即应用并写入配置；自定义壁纸仅保存文件名，禁止路径分隔符和 `..`。
- 中间设置栏按当前模式拆分功能卡片：空战显示空战触发与事件设置，陆战显示陆战触发、CAS 和事件设置；顶部页签与标题保持轻量。
- 事件设置默认收起，使用横向铺满卡片的圆角展开按钮；右箭头表示收起，向下箭头表示展开。
- 背景设置提供“卡片不透明度”滑条，范围 20%–90%，默认 72%；仅调整主界面玻璃卡片叠加层，修改即时生效并持久化。
