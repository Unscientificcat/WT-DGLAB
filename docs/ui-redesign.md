# PySide6 UI 重设计开发文档

## 目标

将 WT-DGLAB 的 tkinter 界面迁移至 PySide6，在不改变游戏读取、强度映射、波形、事件检测和郊狼通信行为的前提下，提供适合 1080p 屏幕的浅色桌面控制界面。

视觉基调为明亮、轻量的游戏控制台：以蓝白为主色，珊瑚粉用于事件强调，薄荷绿用于成功状态。界面可带少量二次元感，但数值、状态和设置始终优先于装饰。

## 范围与边界

- 迁移主窗口、状态栏、实时仪表盘、设置面板、二维码连接区、悬浮窗和注意事项对话框。
- 保持 `config.json` 字段、设置含义和现有业务流程兼容。
- 保持空战、陆战、CAS、击杀/死亡/维修事件、波形、二维码和悬浮窗功能。
- 不新增总开关、紧急归零、通道锁定、用户缩放选择或其他业务功能。
- 不修改 `game_reader.py`、`mapping_engine.py`、`coyote_controller.py` 和 `waveforms.py` 的业务规则。

## 布局规范

- 默认窗口：`1280 x 780`，最小窗口：`1080 x 660`。
- 使用可拖动分栏；宽屏为“实时状态 / 参数设置 / 设备连接”三栏，窄宽度时由分栏收缩而非截断文字。
- 顶部栏显示产品名、WT 状态、郊狼状态、连接地址和注意事项入口。
- 实时状态栏突出当前 G 值或速度，以及 A/B 通道的实时强度。
- 参数设置以当前模式为一级切换，以“基础设置 / 事件设置 / 连接设置”为二级分组；陆战模式保留 CAS 设置。
- 二维码连接区始终位于独立区域，已连接时保留简洁状态反馈。

## 技术方案

- GUI：`PySide6`，以 Python 代码构建控件，QSS 统一样式。
- 定时器：将 tkinter `after()` 替换为 `QTimer.singleShot()`，保留主控制器的调用语义。
- 二维码：继续使用 `qrcode` 和 Pillow 生成，转换为 `QPixmap` 显示。
- 悬浮窗：使用无边框、置顶的 `QWidget`，保留拖动、右键尺寸切换、低频刷新与字段缓存。
- 注意事项：使用阻塞式 `QDialog`，继续从 `注意事项.txt` 读取并高亮 `**关键字**`。
- 打包：在 PyInstaller 参数中收集 PySide6 相关资源，确保单文件程序可启动。
