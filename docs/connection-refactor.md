## 模块与接口

```text
GUI / 游戏事件与映射
        ↓ OutputIntent（双通道完整采样）
ConnectionService → V3 / V4 适配器
                        ├─ OutputRuntime：会话/修订/期限/停止/快照
                        ├─ WaveformPlayer：按时间读取连续帧
                        ├─ OutputTelemetry：预计播放时间
                        └─ V4Rpc + DeviceRegistry（V4）
```

- `OutputIntent(a, b, source, expires_at)`：A/B 均为 `ChannelTarget(strength, WaveformConfig)`；期限为 monotonic 绝对时刻。相同目标、波形与来源仅续期；更新期限不会重新播放波形。
- `submit_output()` 非阻塞且原子提交双通道采样。硬件协议仍按通道下发，不宣称两通道在物理上同时生效。
- `stop_output(channel=None)` 使旧意图失效并提交优先停止；恢复必须提交新有效意图。
- `snapshot()` 返回冻结的 `ConnectionSnapshot`，包含会话、状态、二维码、候选设备、当前设备和 A/B 状态。通道目标、命令基准、App 上报及上报时间彼此独立。
- V4 `select_device(slot_id)` 后台执行，先停止旧设备再初始化新设备。临时 App/slot ID 不写入用户配置。
- 旧 `set_strength_a/b`、`set_waveform_a/b`、`clear_all` 入口保留；主程序已经迁移到原子输出接口。期限保证针对新的 `submit_output` 接口，旧独立调用者应迁移。

## 连接与输出行为

V3 使用本机服务；V4 连接官方或自定义 Relay。连接服务在后台串行启动、替换和重试，故障停止后等待 5 秒重试。GUI 网络操作不阻塞。

V4 只使用首个接入 App。唯一可用候选自动选择，多候选等待手选；设备掉线后只自动等待原槽位恢复，其余设备必须手选。官方描述符未携带蓝牙状态时允许兼容初始化；明确 `hasDevice=false` 或 `connectState=disconnected` 时禁止输出。V3 蓝牙状态始终未知。

每次连接／设备会话改变，取消旧请求并撤销旧输出。游戏事件携带产生时的会话标识，旧会话或未就绪期间的事件不进入新设备。初始化清理完成后，使用新游戏采样恢复常态联动。

事件绝对期限和游戏数据有效期独立于 GUI 检查。25ms 看门狗检查到期；游戏采样超过 1 秒未更新则停止。维修是持续状态，由实际新游戏采样续期，其余有限事件使用产生时间计算的绝对截止时间。

V4 停止执行 `device.op.clear` → `t:7,v:0`，只接受正常完成的强度任务响应；不会在归零后立即 clear。失败仍尝试后续归零，A 失败不跳过 B。非零目标由已确认命令基准计算相对增量，响应丢失不能重复累加同一增量。

App 上报仅用于显示和偏差检测。发送后 1 秒隔离窗口内的报告不会成为后续增量基准；窗口外连续两次不一致触发先归零再恢复。连续三轮偏差不能收敛、三次强度恢复失败或波形任务失败时，通道停止并提示重新连接。App 上限先钳制，静音停止输出；V3 解析 `StrengthData` 获得强度与上限。

源码不把 RPC 完成响应等同于电极输出实测。物理链路断开时无法保证远端已收到停止；界面和日志保留“停止未确认／状态未知”，重新接入必须初始化归零。

## 波形与界面

每帧为 100ms，连续读取十帧组成一秒窗口。V3 预充两秒、每秒补一秒；V4 每 500ms 替换一秒窗口。幅度仍按目标强度缩放，恒定模式频率规则保留。强度变化不重置波形进度；换波从首帧开始。

连接面板区分等待 App、等待设备、待选择、初始化、就绪、恢复、停止和错误。显示目标与 App 上报，不以预测值冒充上报。报告过期仍显示其年龄，未收到则显示未知。

曲线记录已发送帧的预计播放时刻，清理被替换的未来帧，仅绘制到当前时刻，并标注“非设备电压实测”。
