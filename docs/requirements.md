# 项目需求规格

## 项目概述

**WT-DGLAB** 是一款 Windows 桌面软件，将战争雷霆（War Thunder）游戏数据与郊狼 3.0（Coyote 3.0）电击设备联动，实现游戏数据实时驱动电击反馈。

## 核心需求

### R1 — 飞机过载电击联动
- 读取战争雷霆实时过载数据（G-force / `ny` 字段）
- 用户配置过载下限（如 1G）→ 电击强度 0
- 用户配置过载上限（如 10G）→ 电击强度最大
- 中间值线性映射为电击强度

### R2 — 坦克损伤电击联动
- 读取战争雷霆坦克损伤数据（损毁部位数量 / 部件血量）
- 用户配置损伤下限 → 电击强度 0
- 用户配置损伤上限 → 电击强度最大
- 中间值线性映射为电击强度

### R3 — 用户交互界面
- 连接状态显示（WT 状态、郊狼状态）
- 实时数据面板（当前过载/损伤数值、电击强度进度条）
- 参数设置面板（上下限、通道强度等）
- 手动切换飞机/坦克模式
- 在右侧连接区域选择 DG-LAB V3 或 V4 App
- QR 码显示区（手机扫码连接）
- 淡蓝色主题，简洁直观

### R4 — 双通道支持
- 支持郊狼 A/B 两个通道独立设置最大强度
- 两个通道同时输出不同的电击强度
  - A 通道强度 = 主映射值
  - B 通道强度 = 主映射值 × (B_max / A_max)

### R5 — 参数持久化
- 所有用户设置保存为 JSON 文件
- 软件启动时自动加载上次配置
- 支持一键恢复默认设置

### R6 — DG-LAB App 双协议
- V3 模式保留本机 WebSocket 服务端和旧版 App 扫码绑定流程
- V4 模式连接官方或用户自建 Relay，生成带 `tid` 的 4.x App 配对二维码
- V4 App 接入后唯一可用郊狼自动选择，多个候选由用户选择；当前设备断开不自动换控其他设备，支持 A/B 强度、波形与归零
- 协议、V3 端口和 V4 Relay 地址均持久化；旧配置默认使用 V3

### R7 — 多语言 HUD 事件
- 自动识别英语、俄语、法语、德语、简体中文、繁体中文和日文的击落、击毁与坠毁 HUD 文本
- 不要求用户手动选择游戏语言
- 继续使用玩家昵称区分击杀方和被击杀方
- 普通损伤、点燃和无关玩家的 HUD 消息不得误触发事件

### R8 — 常态触发非线性曲线
- 空战过载触发、陆战速度触发与 CAS 过载触发均支持三种触发曲线：线性、指数（低值段温和、高值段陡增）、对数（低值段明显、高值段平缓）
- 非线性曲线提供可调"陡度"参数（1.5~4.0），陡度越大非线性越明显；选择线性时陡度无效
- 曲线变换只改变归一化输入到强度的过渡形状，不改变过载/速度上下限的含义，也不影响边界钳制行为
- 曲线选择与陡度按模式独立配置并持久化；非法配置回退线性

### R9 — 陆战部件损伤短脉冲
- 陆战驾驶坦克时，载具部件（履带、引擎、炮管等）或乘员被打坏的瞬间触发一次短时定强输出（基于 `/indicators` 结构化损伤数据，无语言差异）
- 一发炮弹同时打坏多个部件只触发一次；部件修复后再次被打坏会再次触发
- 输出时长、A/B 通道强度与波形可配置；默认低强度、0.5 秒
- 两次触发之间有可配置冷却时间（默认 2 秒），防止连发战斗刷屏
- 部件损伤不打断进行中的击杀、被击毁或维修事件；死亡等待重生期间不触发
- CAS 上飞机时不检测；空战模式无此事件
- 说明：8111 端口无普通命中记录（hudmsg damage 流仅含击毁/重创/点燃/坠毁），"每次被命中"无法实现，故以部件损伤边沿替代

### R10 — 陆战静止惩罚
- 陆战驾驶坦克时，速度持续低于静止判定阈值（默认 2 km/h）超过设定秒数（默认 10 秒）后，以设定强度与波形持续输出电击，直到恢复移动才停止
- 目的是阻止玩家长时间躲在掩体后挂机，被迫保持机动
- 维修中、乘员全灭（被击毁）与死亡等待重生期间豁免并重置计时
- 被击毁后进入死亡封锁：选车界面与复活出生点的静止不计时，复活后首次开动解除封锁；出生点长时间不动仍会被罚
- 击杀/被击毁/维修/部件损伤事件输出优先于静止惩罚；事件期间静止计时继续累计，事件结束后若仍静止则立即进入惩罚
- 上飞机（CAS）、离开对局或数据无效时重置惩罚状态与死亡封锁
- 超时秒数、静止判定阈值、A/B 通道强度与波形均可配置并持久化
